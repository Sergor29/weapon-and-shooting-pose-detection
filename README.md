# Система распознавания оружия и поз стрельбы

## Краткое описание
Данный проект представляет собой программу компьютерного зрения для автоматического обнаружения оружия и распознавания поз, связанных с его применением, в видеопотоке. Решение направлено на повышение безопасности в общественных местах, на объектах критической инфраструктуры и в образовательных учреждениях путем проактивного выявления угроз.

## Техническое задание (ТЗ)

### 1. Цель и задачи проекта
**Цель:** Создать систему автоматического анализа видеопотока для детекции оружия и опасных поз стрельбы с высокой скоростью и точностью.

**Задачи:**
- Обучить нейросетевую модель для детекции оружия (на базе архитектуры YOLO).
- Обучить модель для распознавания поз стрельбы.
- Разработать архитектуру приложения для обработки видеопотока.
- Доработать пользовательский интерфейс (UI) для отображения результатов.
- Протестировать систему и подготовить её к сертификации.

### 2. Целевая аудитория 
Проект ориентирован на сегменты B2G и B2B:
- **Правоохранительные органы:** Росгвардия, МВД, ФСИН, ФСБ.
- **Крупные корпорации:** Нефтегазовые и химические предприятия, транспортные хабы (аэропорты, вокзалы), ТРЦ, частные охранные предприятия (ЧОП).
- **Социальные учреждения:** Университеты, школы, объекты детского отдыха.

### 3. Проблемы, которые решает приложение
- **Человеческий фактор:** Операторы видеонаблюдения устают, теряют концентрацию и могут пропустить начало инцидента.
- **Низкая скорость реакции:** Традиционные системы лишь фиксируют факт преступления, не позволяя предотвратить его.
- **Высокий уровень ложных срабатываний:** Системы часто путают бытовые предметы (телефон, дрель) с оружием, что снижает доверие к автоматизации.

### 4. Аналоги
В отличие от существующих решений, предложенная система предлагает:
- **Двухэтапную модель:** Анализируется не только предмет, но и контекст (поза человека).
- **Учет российской специфики:** Обучение на уникальном датасете, учитывающем типы оружия, распространенные в РФ, и планировку помещений.
- **Суверенность:** Полное развертывание на инфраструктуре заказчика без передачи данных в облако.

### 5. Описание работы приложения (Тип проекта)
- **Тип:** Кроссплатформенное десктопное приложение (Windows/Linux) с возможностью интеграции в существующие системы видеонаблюдения через API.
- **Принцип работы:**
    1. Приложение получает видеопоток с камер (RTSP, файл).
    2. Нейросетевая модель (YOLO) производит детекцию кадров в реальном времени (менее 200 мс).
    3. При обнаружении оружия или характерной позы система отправляет уведомление оператору.
    4. Все данные сохраняются локально на сервере заказчика.

### 6. Инструменты для разработки
- **Язык программирования:** Python 3.9+

- **Фреймворк для интерфейса:** PyQt / Tkinter (для прототипа)
- **Инструменты разметки:** CVAT (Computer Vision Annotation Tool)
- **Система контроля версий:** Git
- **Инфраструктура:** Docker, Nginx (для API Gateway)
- **Среда разработки:** VS Code
